# Protein Sequence Analyzer

## Background

Proteins are essential biological molecules.
Their amino acid sequences determine their structures and functions.

This project aims to build a simple tool to analyze protein sequences
using Python.

## Objectives

- Read protein sequences
- Calculate sequence length
- Count amino acid composition
- Calculate basic sequence properties

## Skills

- Python
- Bioinformatics
- Protein sequence analysis
- Biopython
